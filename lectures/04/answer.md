# 第4回 解答

## 演習

配布の10件を、用語集の参照と評価基準に照らしてラベル付けした。ラベル案の作成にはAIを使用した。用語集にないRAGについて、未掲載と明示して一般的な説明を付けた回答（#05）は、根拠を暫定的に合格とし、迷った項目として記録した。

採点モデルは gemini-3.5-flash-lite とした。根拠の基準を修正し、未掲載と明示して用語集の記載と区別した一般的な説明は合格と定めた。同じ10件と同じラベルで再採点した。

| 基準 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 根拠 | 8/9 | 10/10 |
| 範囲 | 10/10 | 10/10 |
| ヒント | 10/10 | 10/10 |
| 分かりやすさ | 9/10 | 9/10 |
| 回の表示 | 10/10 | 10/10 |
| 総合の一致 | 9/9 | 10/10 |
| 自動判定できた回答 | 9/10 | 10/10 |
| 要確認（採点モデルが unsure と判定した項目） | 1件 | 0件 |

#05の根拠に対するモデル判定は unsure → pass だった。要確認は一致率の分母から外れるため、一致数と比較可能だった件数を併せて見る必要がある。#04は量子化の違いを答えている一方、同じ説明を繰り返すため、分かりやすさを不合格にした。評価基準を独立に適用すると、このように同じ回答でも基準ごとに判定が分かれる。

## 宿題

選んだレベルは**基礎**。演習で修正した採点基準、配布ケース、ラベルを固定し、採点モデルだけを gemini-3.5-flash-lite から gemini-3.5-flash に変更した。

| 基準 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 根拠 | 10/10 | 9/10 |
| 範囲 | 10/10 | 10/10 |
| ヒント | 10/10 | 10/10 |
| 分かりやすさ | 9/10 | 10/10 |
| 回の表示 | 10/10 | 10/10 |
| 総合の一致 | 10/10 | 10/10 |
| 自動判定できた回答 | 10/10 | 10/10 |
| 要確認（採点モデルが unsure と判定した項目） | 0件 | 0件 |

判定が変わった項目は #08 根拠（pass → fail）、#08 分かりやすさ（fail → pass）。 回の表示はコードが担当するため、モデルを替えても同じ結果だった。10件を各モデルで1回ずつ試した結果であり、モデル選定に使う場合は、ケースを追加して再現性を確かめたい。
